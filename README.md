# Liminal Reverie (NeoForge 1.21.1) — VERSÃO DE TESTE

Mod de dreamcore / espaços liminares. NÃO é terror.

## Como obter o .jar (sem instalar nada)
1. Crie um repositório no github.com e suba o CONTEÚDO desta pasta (inclusive a pasta oculta `.github`).
2. Aba **Actions** > aguarde o build > baixe o artefato **mod-jar**.
3. Coloque o `.jar` em `mods/` (NeoForge 1.21.1). Se o build falhar, copie o erro e me mande.

## Como testar rápido
- Crie um mundo com cheats. `/reverie teleport lobby` leva direto ao Saguão.
- Tecla **J** abre o Diário. `/reverie progress`, `/reverie chapter <1-5>`, `/reverie memory <1-32>`,
  `/reverie event <id>`, `/reverie ending <wake|stay|remember|window>`, `/reverie reset`.
- Jogo normal: 10 min no mundo comum e uma porta de madeira aparece perto de você (Capítulo 1).

## O que já existe
Dimensão The Reverie, 11 áreas construídas por código (Saguão, Escola, Piscina, Hotel, Shopping,
Campos, Sala de Estar, Terraço, Trem, Quarto, Último Quarto), 4 NPCs, 12 puzzles, 32 memórias,
12 símbolos, 13 eventos de sonho, diário com 5 abas, progresso salvo no mundo, 4 finais.
